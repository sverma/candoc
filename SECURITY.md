# Security

Do not include API keys, passwords, resumes, candidate details or database exports in public issues. Report reproducible security defects privately through the repository owner's GitHub profile or private security advisory when available.

The deployed database is isolated on the Compose network. Files are private, generated names are used for storage, sessions are hashed in the database, and production cookies require HTTPS. API writes check allowed origins. Provider requests use fixed hosts and bounded timeouts; arbitrary profile URLs are never fetched.

Email control verification is required for role publication and application contact sharing. It does not verify company identity, recruiter authority or candidate qualifications. Verification links are hashed, single-use, superseded by newer links and expire after 24 hours. Password recovery requires a configured mail service; reset links are single-use, expire after 20 minutes, and invalidate all sessions when consumed. Both mail tasks are process-local best effort. The operator must provide a monitored contact channel and review company access before a broad public launch. There is no automated abuse moderation. AI outputs, resume claims and public source metadata are unverified.

Applications, messages, interviews and offers are scoped to their candidate and role owner. Draft roles are private to their owner; existing applicants retain access to their role after closure. A direct application explicitly grants the role owner access to the professional profile, without granting access to raw resumes or LinkedIn imports. Nationality and authorization declarations require separate opt-ins before professional disclosure; permit notes remain private. Those fields never enter resume evaluation or semantic review. Authorization filters use explicit, current, shared declarations with no inference from nationality or geographic groups. Offers and hiring stages require human actions, not scoring decisions.

Live account deletion cascades linked hiring records and conversations. Account exports include conversations and records shared with the account, but omit token hashes, credentials, private documents and unshared preferences of other users. Recipients can retain their own previously downloaded copies. Backups retain deleted data for up to seven days as described in README.

Dependency inputs are pinned in Python requirements and the npm lockfile. Update, test and rebuild periodically. Never expose PostgreSQL or the internal API port publicly. Backups contain candidate data and are stored separately from source code.
